# Support

Open an issue at:

https://github.com/zhanghao1903/macos-computer-use/issues

Include:

- plugin version and Codex version;
- operating system and Python version;
- sanitized `workflowctl.py status` output;
- lifecycle stage and command name;
- error `kind` and bounded message;
- whether the marketplace is Git or local;
- minimal reproduction steps.

Do not include tokens, cookies, authorization headers, private source, raw
prompts, transcripts, diffs, package credentials, signed URLs, or unredacted
logs.

For corrupt state, preserve the exact project state directory before further
changes. For a failed publication, do not submit a different target or digest
under the old authorization.

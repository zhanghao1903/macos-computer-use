# Architecture

Package-level architecture notes for the app-control package suite.

- [computer-use-macos](computer-use-macos.md): generic macOS app-control
  backend, runtime modes, Accessibility query/action boundary, safety policy,
  and selector-engine direction.
- [wechat-desktop-tool](wechat-desktop-tool.md): WeChat semantic adapter,
  normalized WeChat models, scoped Accessibility search strategy, selector
  profile direction, and safety boundaries.

Keep this directory limited to architecture documents that describe stable
package boundaries, component ownership, and long-lived system structure.
Detailed technical designs for new or proposed features belong in
[`../feature/`](../feature/).
